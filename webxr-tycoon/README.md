# WebXR Tycoon Game

This folder contains a browser-based 3D tycoon prototype designed for WebXR-compatible browsers.

## How to run

From this folder:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Features

- 3D storefront scene
- Simple business simulation
- Staff hiring
- Upgrade purchases
- Inventory restock
- Pricing controls
- Revenue, expenses, and profit tracking
- VR button for immersive WebXR sessions on compatible hardware

## Notes

- Some features require a browser with WebXR support.
- For full VR immersion, use a browser on a supported headset or desktop with WebXR enabled.
