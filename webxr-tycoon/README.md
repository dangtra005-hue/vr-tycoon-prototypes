# WebXR Tycoon (Advanced)

This folder contains a more advanced version of the browser-based tycoon prototype.

## Advanced features

- realistic financial simulation
- staff, pricing, marketing, and upgrade controls
- evolving market events and trend behaviour
- business dashboard with charts and KPI cards
- immersive storefront scene with animated customer activity
- WebXR-compatible start flow

## Run locally

```bash
cd webxr-tycoon
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Notes

- VR activation is available in browsers and devices that support WebXR.
- The current prototype focuses on the game loop, realistic business decisions, and immersive presentation rather than full 3D physics or full multiplayer.
